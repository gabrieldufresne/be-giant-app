## Summary
Discover is the Search tab: browse at rest, search when the field is used (D3). At rest: topics, trending, video and short stories first, then Near you and Discover by province (D39). Typing shows tag suggestions and instant story results; submitting shows the full list with filter chips. Topics are filters, not hub screens (D12). The prototype searches its bundled stories on the device; the build calls the website's search endpoint. Values are iOS points.

## States
- **Idle:** DISC-04 to DISC-10. **Focused, empty:** DISC-11; keyboard up, tab bar and Search button hidden. **Typing:** DISC-12, DISC-13. **Results:** DISC-15, DISC-16. **No results:** DISC-17, with or without filters.
- **Guest:** no account city, so Near you shows the ask card unless About you or location gave one.
- **Loading** (instant results pending, results pending, idle sections), **error** (search failed; the API returns `error: "Search temporarily unavailable"` with empty hits), **offline** (proposal: search Saved stories only, with a note), **location denied**, **end of a long list** (paging): Not designed.

## Accessibility
- Labels in the prototype: "Clear" only. Chips, filter chips, rows, tiles, Cancel, See all and province tiles have no roles; chips need a selected state ("Selected").
- Trending numbers are decorative; read the title first. The highlight is visual only. Results need a swipe-to-save custom action. Announce the result count when it changes.
- Targets all 44pt or more (chips, Cancel, Clear, See all 44; recent rows 48; suggestions 52; tiles 58).
- Contrast: `#A6A6A6` "No stories yet" fails AA (use `#7A7A7A`); trending numbers in `#A6A6A6` are decorative.
- Dynamic Type: Not specified; the province grid and rails need a large-text layout.

## Data and analytics
- **Endpoint:** the website's `/api/search` (params `q`, `type`, `pillar`, `topic`, `articleType`, `page`, `perPage`; returns `hits`, `facets`, `found`, `page`, `totalPages`). Index types: article, author, topic, pillar, series. Field Office to confirm the app may call it directly, or wrap it.
- **Missing in schema (for the change request):**
  - `article.place` (SCR-01): object `{city: string, province: string (two-letter code, e.g. "ON")}`, optional; national stories leave it empty. Filled by editors when publishing (Q14 asks who). Without it Near you (DISC-09), province tiles and counts (DISC-10) and place search break. Index `place.city` and `place.province` in Typesense too.
  - `shortStory.article` (SCR-03): see `05-home-and-for-you.md`; also needed to index shorts if search is to cover video.
- **Not schema, but needed:** a series filter on `/api/search`; image hotspot in search hits; an index for `shortStory` if the no-results copy stays.
- **Proposed events:** discover_view, topic_chip_tap, trending_open (rank), discover_video_open, short_story_open, near_you_open, near_you_location_ask, near_you_location_result (granted, denied), province_tap, search_focus, search_submit (query length, result count), tag_suggestion_tap (kind), instant_result_open (position), filter_toggle (pillar, series), search_no_results (query), try_suggestion_tap, recent_search_tap, swipe_save (screen: search).
